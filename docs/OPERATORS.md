# 운영자 명단과 권한 (2026-09-29)

- 운영자는 운영 콘솔을 포함해 앱의 모든 기능을 쓴다. 온보딩 · 홈 · 명함 · 테이블토크 · 커피챗 · 포스터를 참가자와 똑같이 쓰고, 계산 서비스도 참가자처럼 운영진(role=staff)을 주소 · 배정 · 추천에 넣는다.
- 홈 상단에 운영자에게만 `운영 콘솔` 링크가 보인다. 명함 이름 검색에서도 운영진이 참가자와 같이 찾힌다.
- 저장소 코드 수정(머지)과 DB · SQL 변경은 박성하만 한다. 다른 운영자는 콘솔 화면으로만 운영한다.

## 권한을 정하는 곳

1. 앱은 `participants.is_admin` 만 본다(`apps/web/app/(modules)/ops/layout.tsx`, `lib/session.ts` 의 `requireAdmin`). 로그인할 때 쿠키에 담기므로 값을 바꾼 뒤에는 다시 로그인해야 반영된다.
2. 적재 스크립트 `scripts/import_participants.py` 의 `OPERATORS` 가 이 표의 이름과 같다. 명단에 있는 이름은 `is_admin` 을 켜고 없는 이름은 끈다. 명단에 있는데 CSV 에 없으면 경고한다.
3. 명단을 바꿀 때는 이 문서와 `OPERATORS` 를 같이 고친다.

## 로그인 숫자

운영자의 숫자 4자리는 저장소에 적지 않는다. 적재 때 `--pin-out` 파일이나 콘솔의 숫자 재발급으로 개별 안내한다.
